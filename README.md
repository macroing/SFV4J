SFV4J
=====
SFV4J is a simple file viewer for Java. It is both an application and a library.

Getting Started
---------------
To clone this repository, you can type the following in Git Bash.

```bash
git clone https://github.com/macroing/SFV4J.git
```

Supported Features
------------------
 - You may open any file and view basic information about it, including its hexadecimal data.
 - Files with the `CSV` file format allows you to view the tabular data in a table.
 - Files with the `OpenEXR` file format allows you to view its structure in a tree view.

Dependencies
------------
 - [Java 8 - 17](http://www.java.com).
